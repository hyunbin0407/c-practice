# 과제 — 조건문·배열·반복문 활용

## 학습 날짜
2026-10-08

## 핵심 개념 요약
- `scanf`로 여러 개의 정수를 한 번에 입력받기 (`%d %d %d`)
- 정수 나눗셈(`/`)과 나머지(`%`) 연산으로 자릿수/시분초 분리하기
- 배열에 각 자릿수를 저장하고 `for` 반복문으로 비교하기
- 조건문(`if` / `else if` / `else`)으로 분기 처리하기
- 삼항 연산자(`?:`)로 조건식을 값으로 바로 표현하기

## 코드 파일
- `Baseball.c` — 숫자 야구 게임: 정답과 추측 숫자를 각 자릿수로 분리해 비교, 스트라이크/볼/불일치 개수와 정답 여부를 출력
- `End time.c` — 시작 시각(시/분/초)과 작업 소요 시간(초)을 입력받아 종료 날짜(며칠 뒤)와 종료 시각을 계산해 출력
- `Receipt.c` — 빵/음료 수량과 지불 금액을 입력받아 총 구매 금액과 거스름돈(또는 부족한 금액)을 계산해 출력

## 컴파일 및 실행 방법
```bash
clang 파일명.c -o 파일명
./파일명
```
예)
```bash
clang Baseball.c -o Baseball
./Baseball
```
파일명에 공백이 있는 경우(`End time.c`)는 따옴표로 감싼다.
```bash
clang "End time.c" -o "End time"
./"End time"
```

## 헷갈렸던 점
- `Baseball.c`: 볼 판정 시 이미 스트라이크로 확정된 자리까지 다시 비교 대상에 포함되어, 엄밀한 숫자 야구 규칙과는 차이가 있을 수 있음 (중복 숫자가 없는 입력 기준으로는 정상 동작).
